Lab 05: Call Microsoft Graph App-Only from Python

Build the nightly user report as a Python daemon: no signed-in user, a client credential from the environment, and paging through every user in the tenant.

VS Code · PythonIntermediate~15 min

Scenario and Objectives

A scheduled job must list every user and whether the account is enabled. Nobody signs in when it runs, so it uses app-only access with the daemon app from Lab 02.

  • Authenticate with ClientSecretCredential and the .default scope.
  • Read the client secret from an environment variable, never from code.
  • List users with $select and $top, and follow every page.
  • Catch ODataError for a missing user.
Note: Lab 06 builds the same job in Java. Do either one, or both to compare the SDKs.
Related topic: Delegated and App-Only Access · Choose a Credential

Architecture

flowchart LR

    JOB -->|client ID + secret| ENTRA[Microsoft Entra ID]
    ENTRA -->|app-only token| JOB
    JOB -->|GET /users, paged| GRAPH[graph.microsoft.com]
    GRAPH --> USERS[(All users)]
    class ENV data
    class JOB azure

The job proves its own identity with the secret. The token carries the User.Read.All app role that an admin consented to in Lab 02.

Prerequisites and Names

  • The graph-workshop-daemon-<suffix> app from Lab 02 with User.Read.All (Application) granted, and its client secret value.
  • Python 3.10 or later and the VS Code Python extension.
  • On Windows, Windows long path support enabled (see Step 2), or WSL.
Environment variableValue
GRAPH_TENANT_IDDirectory (tenant) ID

export GRAPH_DAEMON_CLIENT_ID="<daemon-client-id>"
read -rsp "Daemon client secret: " GRAPH_DAEMON_CLIENT_SECRET && export GRAPH_DAEMON_CLIENT_SECRET

New-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem" `
    -Name "LongPathsEnabled" -Value 1 -PropertyType DWORD -Force

Step 3: Write main.py

Create main.py with this code. The SDK is asynchronous, so the work runs inside asyncio.run. Paging uses with_url(page.odata_next_link) to request each next page.

main.py 
import asyncio
import os

from azure.identity.aio import ClientSecretCredential
from kiota_abstractions.base_request_configuration import RequestConfiguration
from msgraph import GraphServiceClient
from msgraph.generated.models.o_data_errors.o_data_error import ODataError
from msgraph.generated.users.users_request_builder import UsersRequestBuilder


async def main() -> None:
    credential = ClientSecretCredential(
        tenant_id=os.environ["GRAPH_TENANT_ID"],
        client_id=os.environ["GRAPH_DAEMON_CLIENT_ID"],
        client_secret=os.environ["GRAPH_DAEMON_CLIENT_SECRET"],
    )
    client = GraphServiceClient(credentials=credential, scopes=["https://graph.microsoft.com/.default"])

    query = UsersRequestBuilder.UsersRequestBuilderGetQueryParameters(
        select=["displayName", "mail", "accountEnabled"],
        top=5,
    )
    config = RequestConfiguration(query_parameters=query)

    try:
        page = await client.users.get(request_configuration=config)
        count, pages = 0, 0
        while page:
            pages += 1
            for user in page.value or []:
                count += 1
                print(f"{count:3}. {user.display_name} <{user.mail or 'no mail'}> enabled={user.account_enabled}")
            if not page.odata_next_link:
                break
            page = await client.users.with_url(page.odata_next_link).get()
        print(f"\n{count} users across {pages} page(s)")

        await client.users.by_user_id("00000000-0000-0000-0000-000000000000").get()
    except ODataError as error:
        print(f"\nHTTP {error.response_status_code}: {error.error.code if error.error else 'unknown'}")
        print(f"Message: {error.error.message if error.error else ''}")
    finally:
        await credential.close()


asyncio.run(main())

  • No browser sign-in happened: the job authenticated as the app.
  • Every user in the tenant is listed, numbered continuously across pages.
  • The missing user produced a handled 404, not a stack trace.
  • main.py contains no IDs or secrets.

Stretch Goals

  • Add a call to await client.me.get() and read the error: /me needs a signed-in user, so it can't work app-only.
  • Change top to 999 and compare the number of pages.
  • Add filter="accountEnabled eq false" to the query parameters to list only disabled accounts. See Filter on the Server for Performance.
  • In Lab 02, select Revoke admin consent for User.Read.All, wait a minute, run the job again, and read the 403. Grant consent again afterward.

Troubleshooting

SymptomCheck
AADSTS7000215 invalid client secret, or AADSTS7000222 expired secretYou used the Secret ID instead of the Value, or the secret expired. Create a new secret in Lab 02, Step 7.
AADSTS90002 tenant not foundGRAPH_TENANT_ID is wrong. Copy the Directory (tenant) ID again.
AADSTS700016 application not foundGRAPH_DAEMON_CLIENT_ID is wrong, or the app is in a different tenant.
403 Authorization_RequestDeniedAdmin consent for User.Read.All (Application) is missing or was just granted. Check the status in Lab 02, wait a minute, and run again.
KeyError: 'GRAPH_TENANT_ID'Set the variables in the same terminal (Step 1).
OSError during pip install on WindowsEnable long paths (Step 2) or use WSL.
ModuleNotFoundError: No module named 'msgraph'Activate the virtual environment, then run again.

Cleanup and References

  1. Clear the secret from your session: Remove-Item Env:GRAPH_DAEMON_CLIENT_SECRET (PowerShell) or unset GRAPH_DAEMON_CLIENT_SECRET (Bash).
  2. Run deactivate, then delete the graph-lab05-python folder.
  3. If you're also doing Lab 06, keep the daemon app. Otherwise, delete both app registrations as described in Lab 02 cleanup. An unused daemon with a valid secret and User.Read.All is a standing risk.
