Lab 06: Call Microsoft Graph App-Only from Java

Build the nightly user report as a Java daemon: no signed-in user, a client credential from the environment, and PageIterator to read every user in the tenant.

VS Code · JavaIntermediate~15 min

Scenario and Objectives

A scheduled job must list every user and whether the account is enabled. Nobody signs in when it runs, so it uses app-only access with the daemon app from Lab 02.

  • Authenticate with ClientSecretCredential and the .default scope.
  • Read the client secret from an environment variable, never from code.
  • List users with $select and $top, and let PageIterator follow every page.
  • Catch ODataError for a missing user.
Note: Lab 05 builds the same job in Python. Do either one, or both to compare the SDKs.
Related topic: Delegated and App-Only Access · Choose a Credential

The job proves its own identity with the secret. The token carries the User.Read.All app role that an admin consented to in Lab 02.

Prerequisites and Names

  • The graph-workshop-daemon-<suffix> app from Lab 02 with User.Read.All (Application) granted, and its client secret value.
  • JDK 11 or later and Apache Maven 3.9 or later on PATH.
  • The VS Code Extension Pack for Java.

Step 3: Write App.java

Create src/main/java/com/contoso/graph/App.java. The Java SDK is synchronous; PageIterator follows @odata.nextLink for you.

src/main/java/com/contoso/graph/App.java 
package com.contoso.graph;

import com.azure.identity.ClientSecretCredential;
import com.azure.identity.ClientSecretCredentialBuilder;
import com.microsoft.graph.core.tasks.PageIterator;
import com.microsoft.graph.models.User;
import com.microsoft.graph.models.UserCollectionResponse;
import com.microsoft.graph.models.odataerrors.ODataError;
import com.microsoft.graph.serviceclient.GraphServiceClient;

public class App {
    public static void main(String[] args) throws Exception {
        ClientSecretCredential credential = new ClientSecretCredentialBuilder()
                .tenantId(requireEnv("GRAPH_TENANT_ID"))
                .clientId(requireEnv("GRAPH_DAEMON_CLIENT_ID"))
                .clientSecret(requireEnv("GRAPH_DAEMON_CLIENT_SECRET"))
                .build();
        GraphServiceClient graphClient =
                new GraphServiceClient(credential, "https://graph.microsoft.com/.default");

        try {
            UserCollectionResponse firstPage = graphClient.users().get(config -> {
                config.queryParameters.select = new String[] {"displayName", "mail", "accountEnabled"};
                config.queryParameters.top = 5;
            });

            int[] count = {0};
            PageIterator<User, UserCollectionResponse> iterator =
                    new PageIterator.Builder<User, UserCollectionResponse>()
                            .client(graphClient)
                            .collectionPage(firstPage)
                            .collectionPageFactory(UserCollectionResponse::createFromDiscriminatorValue)
                            .processPageItemCallback(user -> {
                                count[0]++;
                                System.out.printf("%3d. %s <%s> enabled=%s%n", count[0],
                                        user.getDisplayName(),
                                        user.getMail() == null ? "no mail" : user.getMail(),
                                        user.getAccountEnabled());
                                return true;
                            })
                            .build();
            iterator.iterate();
            System.out.printf("%n%d users%n", count[0]);

            graphClient.users().byUserId("00000000-0000-0000-0000-000000000000").get();
        } catch (ODataError e) {
            System.out.printf("%nHTTP %d: %s%n", e.getResponseStatusCode(), e.getError().getCode());
            System.out.println("Message: " + e.getError().getMessage());
        }
    }

    private static String requireEnv(String name) {
        String value = System.getenv(name);
        if (value == null || value.isBlank()) {
            throw new IllegalStateException("Set the " + name + " environment variable.");
        }
        return value;
    }
}

  • No browser sign-in happened: the job authenticated as the app.

Stretch Goals

  • Add a call to graphClient.me().get() and read the error: /me needs a signed-in user, so it can't work app-only.
  • Change top to 999: the output is the same, but PageIterator makes far fewer requests.
  • Set config.queryParameters.filter = "accountEnabled eq false"; to list only disabled accounts. See Filter on the Server for Performance.
  • In Lab 02, select Revoke admin consent for User.Read.All, wait a minute, run the job again, and read the 403. Grant consent again afterward.

Troubleshooting

SymptomCheck
AADSTS7000215 invalid client secret, or AADSTS7000222 expired secretYou used the Secret ID instead of the Value, or the secret expired. Create a new secret in Lab 02, Step 7.
AADSTS90002 tenant not foundGRAPH_TENANT_ID is wrong. Copy the Directory (tenant) ID again.
AADSTS700016 application not foundGRAPH_DAEMON_CLIENT_ID is wrong, or the app is in a different tenant.
403 Authorization_RequestDeniedAdmin consent for User.Read.All (Application) is missing or was just granted. Check the status in Lab 02, wait a minute, and run again.
Set the ... environment variable.Set the variables in the same terminal (Step 1).
mvn isn't recognizedInstall Apache Maven and add its bin folder to PATH, then open a new terminal.
invalid target release: 11Maven is using an older JDK. Point JAVA_HOME at JDK 11 or later and check with mvn -v.

Cleanup and References

  1. Clear the secret from your session: Remove-Item Env:GRAPH_DAEMON_CLIENT_SECRET (PowerShell) or unset GRAPH_DAEMON_CLIENT_SECRET (Bash).
  2. Delete the graph-lab06-java folder.
  3. Delete both app registrations as described in Lab 02 cleanup. An unused daemon with a valid secret and User.Read.All is a standing risk.
