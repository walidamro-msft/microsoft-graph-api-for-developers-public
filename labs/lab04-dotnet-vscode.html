Lab 04: Build a C# Console App with the Graph .NET SDK

Sign a user in with device code flow, read their profile, list colleagues across pages, and handle a Microsoft Graph error the way production code should.

VS Code · C#Intermediate~15 min

Scenario and Objectives

You're building an internal command-line tool that greets the signed-in user and shows the people in their organization. It must use the user's own permissions, not a shared secret.

  • Create a .NET console app with the Microsoft.Graph and Azure.Identity packages.
  • Authenticate with DeviceCodeCredential using the Lab 02 public client.
  • Call GET /me with $select.
  • Page through GET /users with PageIterator.
  • Catch ODataError and log the status, error code, and request-id.
Related topic: Microsoft Graph SDKs · Errors and Throttling

Architecture

flowchart TD
    APP[".NET console app"] -->|device code request| ENTRA[Microsoft Entra ID]
    USER[You in a browser] -->|enter code, sign in| ENTRA
    ENTRA -.->|delegated token| APP
    APP -->|GET /me, GET /users| GRAPH[graph.microsoft.com]
    class USER external
    class APP azure
    class ENTRA accent
    class GRAPH azure

The app shows a code, you sign in on any browser, and Microsoft Entra ID returns a token scoped to User.Read and User.ReadBasic.All.

Build

Step 1: Create the Project

  1. Open a terminal in VS Code in a folder outside any Git repository you share.
  2. Create the project and add the packages:
Terminal 
dotnet new console -o GraphLab04
cd GraphLab04
dotnet add package Microsoft.Graph
dotnet add package Azure.Identity
code -r .

Expected result: The project opens in VS Code, and GraphLab04.csproj lists both packages.

Step 2: Set the App Settings

The client ID and tenant ID aren't secrets, but keeping them out of code means you can reuse the app with any registration.

PowerShell 
$env:GRAPH_CLIENT_ID = "<user-app-client-id>"
$env:GRAPH_TENANT_ID = "<tenant-id>"
Bash 
export GRAPH_CLIENT_ID="<user-app-client-id>"
export GRAPH_TENANT_ID="<tenant-id>"

Step 3: Create the Graph Client

Replace the contents of Program.cs with the following. DeviceCodeCredential prints a sign-in message; GraphServiceClient uses the credential to get tokens for the scopes you list.

Program.cs (part 1) 
using Azure.Identity;
using Microsoft.Graph;
using Microsoft.Graph.Models;
using Microsoft.Graph.Models.ODataErrors;

var clientId = Environment.GetEnvironmentVariable("GRAPH_CLIENT_ID")
    ?? throw new InvalidOperationException("Set the GRAPH_CLIENT_ID environment variable.");
var tenantId = Environment.GetEnvironmentVariable("GRAPH_TENANT_ID")
    ?? throw new InvalidOperationException("Set the GRAPH_TENANT_ID environment variable.");
string[] scopes = ["User.Read", "User.ReadBasic.All"];

var credential = new DeviceCodeCredential(new DeviceCodeCredentialOptions
{
    ClientId = clientId,
    TenantId = tenantId,
    DeviceCodeCallback = (info, _) =>
    {
        Console.WriteLine(info.Message);
        return Task.CompletedTask;
    }
});

var graphClient = new GraphServiceClient(credential, scopes);

Step 4: Read the Signed-In User

Append this code. $select limits the response to three properties.

Program.cs (part 2) 
// 1. Signed-in user
var me = await graphClient.Me.GetAsync(config =>
{
    config.QueryParameters.Select = ["displayName", "userPrincipalName", "jobTitle"];
});
Console.WriteLine($"\nHello, {me?.DisplayName} ({me?.UserPrincipalName})\n");

Step 5: Page Through Users

Append this code. $top=5 forces small pages so you can watch PageIterator follow @odata.nextLink. The second callback runs before each additional page request.

Program.cs (part 3) 
// 2. Users in the tenant, 5 per page
var firstPage = await graphClient.Users.GetAsync(config =>
{
    config.QueryParameters.Select = ["displayName", "mail"];
    config.QueryParameters.Top = 5;
});

var count = 0;
var pages = 1;
var iterator = PageIterator<User, UserCollectionResponse>.CreatePageIterator(
    graphClient,
    firstPage!,
    user =>
    {
        count++;
        Console.WriteLine($"{count,3}. {user.DisplayName} <{user.Mail ?? "no mail"}>");
        return true;
    },
    request =>
    {
        pages++;
        return request;
    });
await iterator.IterateAsync();
Console.WriteLine($"\n{count} users across {pages} page(s)\n");

Step 6: Handle an Error

Append this code. The SDK turns Microsoft Graph error responses into an ODataError exception that carries the status code and the error object.

Program.cs (part 4) 
// 3. Error handling
try
{
    await graphClient.Users["00000000-0000-0000-0000-000000000000"].GetAsync();
}
catch (ODataError ex)
{
    Console.WriteLine($"HTTP {ex.ResponseStatusCode}: {ex.Error?.Code}");
    Console.WriteLine($"Message:    {ex.Error?.Message}");
    Console.WriteLine($"request-id: {ex.Error?.InnerError?.RequestId}");
}

  • The error block prints 404, an error code, and a request-id instead of crashing.

Stretch Goals

  • Add an advanced query: set config.QueryParameters.Filter = "endsWith(mail,'@<your-domain>')", config.QueryParameters.Count = true, and config.Headers.Add("ConsistencyLevel", "eventual"). Remember to add the header again in the PageIterator request callback.
  • Remove "User.ReadBasic.All" from scopes, run again, and compare the error from GET /users.
  • Replace DeviceCodeCredential with InteractiveBrowserCredential. You need to add the redirect URI http://localhost under Mobile and desktop applications on the app registration.

Troubleshooting

SymptomCheck
Set the GRAPH_CLIENT_ID environment variable.Set the variables in the same terminal you run dotnet run from (Step 2).
AADSTS7000218 during sign-inAllow public client flows isn't Yes on the user app (Lab 02, Step 3).
AADSTS700016 application not foundGRAPH_CLIENT_ID or GRAPH_TENANT_ID is wrong, or you signed in to a different tenant.
AADSTS65001 consent requiredYour tenant blocks user consent. An admin selects Grant admin consent on the user app.
403 Authorization_RequestDenied on /usersUser.ReadBasic.All is missing from scopes or wasn't consented.
Sign-in blocked by your organizationConditional Access can block device code flow. Use a developer tenant, or try the InteractiveBrowserCredential stretch goal.
