Labs 03 to 06 are independent of each other. Entra ID admins usually choose Lab 03; developers choose the lab for their language.

Before you begin: use a test or developer tenant, not production. Some steps create groups, app registrations, and a client secret, and need admin consent.

Lab Catalog

Lab 01: Explore Microsoft Graph with Graph Explorer

Run queries, use $select, $filter, and advanced queries, consent to a permission, and read an error.

Tool: Browser · Time: ~10 min

Lab 02: Register Apps in Microsoft Entra ID

Create a public client for delegated access and a confidential daemon for app-only access, with admin consent and a client secret.

Tool: Microsoft Entra admin center · Time: ~12 min

Lab 03: Manage Users and Groups with Microsoft Graph PowerShell

Connect with scopes, discover cmdlets and permissions, run an advanced query, and create a security group.

Tool: VS Code, PowerShell 7 · Time: ~15 min

Lab 04: Build a C# Console App with the Graph .NET SDK

Device code sign-in, GET /me, paging with PageIterator, and ODataError handling.

Tool: VS Code, .NET 8+ · Time: ~15 min

Lab 05: Call Microsoft Graph App-Only from Python

An async Python daemon that authenticates with client credentials, pages through every user, and handles errors.

Tool: VS Code, Python 3.10+ · Time: ~15 min

Lab 06: Call Microsoft Graph App-Only from Java

The same daemon in Java with Maven, using PageIterator to follow every page.

Tool: VS Code, JDK 11+ and Maven · Time: ~15 min

Common Prerequisites

  • A Microsoft Entra test or developer tenant where you can register apps and grant admin consent (Privileged Role Administrator or Global Administrator). If you qualify, a Microsoft 365 Developer Program E5 sandbox includes sample users and data.
  • No Azure subscription is needed. The labs use only standard Microsoft Graph APIs.
  • Visual Studio Code, plus the tools for the labs you choose: PowerShell 7, the .NET 8 SDK or later, Python 3.10 or later, or JDK 11 or later with Maven.
  • A short <suffix>, such as your initials, to keep names unique.

Security

Use least-privilege permissions, keep client IDs and secrets in environment variables, and never commit secrets. Delete the lab app registrations when you finish.
