Microsoft Graph API for Developers (1-2 hour hands-on workshop, L200)

Learn how to use Microsoft Graph, the single API for Microsoft 365 and Microsoft Entra ID data, in your apps and automation.

What we will cover:
- What Microsoft Graph is and what it can reach
- App registration, delegated vs. application permissions, and consent
- Building requests: query parameters, paging, errors, and throttling
- The Microsoft Graph SDKs for PowerShell, C#, Python, and Java
- Hands-on labs: Graph Explorer, Microsoft Entra admin center, PowerShell, C#, Python, Java

Who should attend:
- Developers, architects, and Microsoft Entra ID admins

Prerequisites (please complete before the session):
- A Microsoft Entra TEST or developer tenant where you can register apps and grant admin consent
  (Privileged Role Administrator or Global Administrator). Do not use production.
- Visual Studio Code
- For the code labs, at least one of: PowerShell 7, .NET 8 SDK or later, Python 3.10 or later, JDK 11 or later with Maven
- Windows + Python: enable Windows long path support (admin) before the session

Outcome:
By the end of this workshop, you can register a least-privilege app, call Microsoft Graph with an SDK, page through results, and handle errors and throttling.

Workshop site: https://walidamro-msft.github.io/microsoft-graph-api-for-developers/
