Your code runs anywhere. The identity and the data live in a Microsoft Entra tenant.

A Microsoft Entra tenant

Every Microsoft Graph call is made against a tenant. Use a test or developer tenant, never production, while you learn.

The right roles

Rights to register apps and, for app-only access, an admin who can consent to application permissions.

Tools for your language

A browser for Graph Explorer, an editor, and the SDK for the language you build in.

Get a Test Tenant

Do You Need an Azure Subscription?

No, not for the standard Microsoft Graph APIs used in this workshop. They're included with your users' Microsoft 365 and Microsoft Entra licenses. You need an Azure subscription only when your app calls metered APIs, or when you host your app in Azure.

Note: Microsoft 365 data such as mail, calendars, and OneDrive files exists only for users who have the matching license. Directory data such as users, groups, and app registrations is available in any Microsoft Entra tenant.
Learn more: Overview of metered APIs and services

Skills That Help

REST and HTTP

Methods (GET, POST, PATCH, DELETE), URLs with query strings, headers, JSON bodies, and status codes. Microsoft Graph is a REST API.

OAuth 2.0 basics

The Microsoft identity platform issues access tokens using OAuth 2.0. You need to know the difference between a user signing in and an app signing in as itself.

Both are covered in this workshop: OAuth in Authentication and Permissions, REST in Making Requests.

Ready Checklist

  • You can sign in to a test tenant at entra.microsoft.com.
  • Your account can register apps and grant admin consent in that tenant.
  • Graph Explorer opens at aka.ms/ge.
  • The tools for the language you chose are installed.

Key takeaway

You need a tenant and the right roles more than you need an Azure subscription. Set them up first; the tools take minutes.
