Graph Explorer

Try any Microsoft Graph request in your browser, find the permission it needs, and copy the SDK code, before you write a line of your own.

What Is Graph Explorer?

Graph Explorer is a web-based tool that you can use to build and test requests using Microsoft Graph APIs.

Source: Use the Microsoft Graph API, Microsoft Learn

Open it at aka.ms/ge. Nothing to install: you pick a method and a version, type a URL, and select Run query. The response, its headers, and the equivalent SDK code appear underneath.

Signed out

Queries run against a sample tenant with demo data. Read-only, safe, and good for learning the shape of an API.

Signed in

Queries run against your tenant as you, with the permissions you consent to. Required for POST, PATCH, PUT, and DELETE.

Important: Signed in, write requests change real data in that tenant. Sign in to a developer or test tenant, not production.

A Tour of the Interface

Left pane

  • Sample queries: ready-made requests grouped by service.
  • Resources: browse v1.0 and beta resources; export a Postman collection.
  • History: queries from the last 30 days; export as .har.

Query area

  • HTTP method and API version dropdowns.
  • Query box for the URL.
  • Request body and Request headers.
  • Modify permissions and Access token.

Response area

  • Response preview and Response headers.
  • Code snippets for the SDKs.
  • Toolkit component and Adaptive cards when available.

Header

  • Tenant you're using.
  • Settings: theme, and a link to get an instant sandbox with sample data.
  • Profile avatar: sign in, Consent to permissions, sign out.
  • Share (next to Run query) copies a link to the query.
Note: Modify permissions is in preview, and some queries might not list every permission. When in doubt, check the Permissions table on the API reference page.

From Query to Code

flowchart LR

    RUN --> OK{200 OK?}
    OK -->|403| PERM[Modify permissions]
    PERM --> RUN
    OK -->|Yes| SHAPE[Add $select, $filter]
    SHAPE --> SNIP[Copy code snippet]
    SNIP --> APP([Your app])
    class PICK,RUN azure
    class OK neutral
    class PERM warning
    class SHAPE data
    class SNIP success
    class APP external

Iterate in the browser until the response is exactly what your app needs, then move the request into code.

  1. Start from a sample. It gives you a correct URL for the service.
  2. Fix permissions once. A 403 sends you to Modify permissions; pick the least-privileged option and note it for your app registration.
  3. Shape the response. Add $select and $filter until it returns only what you need.
  4. Copy the snippet. The Code snippets tab shows the same request in SDK code, for example C#, Java, JavaScript, Go, and PowerShell.

Request 
GET https://graph.microsoft.com/v1.0/users?$select=displayName,mail&$top=2
Response preview (shortened) 
{
  "@odata.context": "https://graph.microsoft.com/v1.0/$metadata#users(displayName,mail)",

  "value": [
    { "displayName": "Adele Vance", "mail": "AdeleV@contoso.com" },
    { "displayName": "Alex Wilber", "mail": "AlexW@contoso.com" }

}
PartWhat it tells you
Status code (above the preview)200 succeeded; anything else has an error object instead of data.
@odata.contextThe resource type and the properties you selected.
valueThe collection. Single resources, such as /me, return the object directly.
@odata.nextLinkMore pages exist. Your code must follow this URL.
Response headers > request-idThe ID to log and to give Microsoft support.

Use It Safely

Protect the access token

The Access token tab shows a live token for your account. Don't paste it into chat, tickets, or shared tools.

Consent is recorded

Consenting adds Graph Explorer as an enterprise application in your tenant with the permissions you granted. Admins can review or revoke them under Entra ID > Enterprise apps.

Least privilege still applies

Consent only to what the current query needs. Avoid Directory.* permissions for exploration.

Key takeaway

Use Graph Explorer to learn, prototype, and find permissions, using your own delegated access in a test tenant. Move to code or PowerShell for anything repeatable, app-only, or in production.
